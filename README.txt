Hunan Adventure 2026 — Ready-to-upload static site

STRUCTURE
- index.html                Main page
- assets/site.css           Styling
- assets/site.js            Expandable itinerary interactions
- assets/images/README.txt  Reserved local image folder
- README.txt                This guide

QUICK VIEW
Unzip the package and open index.html in a browser.

PUBLISH A PUBLIC LINK
Netlify Drop (easiest):
1. Unzip the ZIP.
2. Go to https://app.netlify.com/drop
3. Drag the entire hunan_adventure_2026_site folder onto the page.
4. Netlify generates a public URL you can share.

Also compatible with GitHub Pages, Cloudflare Pages and Vercel. Upload the entire folder as a static site; index.html is at the root.

DEPENDENCIES
- Destination photos are loaded from credited public web image URLs.
- YouTube videos are embedded and require internet access.
- No build system, npm packages or server is required.

TRAVEL NOTE
Reconfirm flight voucher conditions, attraction arrangements, ticket prices and rail schedules before booking.
